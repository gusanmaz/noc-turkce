Nature of Code - Bölüm 0

Bu Bölümde Neler Öğreneceksiniz?

Bu bölümde rastgelelik ve gürültü (noise) kavramlarını öğreneceksiniz. Doğal görünümlü hareketler, organik desenler ve öngörülemeyen davranışlar oluşturmanın temellerini atacağız.

🎯 Neden Rastgelelik?

Doğa mükemmel düzen içinde değildir. Yapraklar tam simetrik düşmez, böcekler düz çizgide yürümez. Simülasyonlarımıza rastgelelik ekleyerek onları daha gerçekçi ve ilginç hale getirebiliriz.

  • random(): Tamamen rastgele değerler
  • noise(): Yumuşak, organik rastgelelik (Perlin Noise)
