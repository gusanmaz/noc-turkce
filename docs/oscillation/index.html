🌊 Salınım

Nature of Code - Bölüm 3

Bu Bölümde Neler Öğreneceksiniz?

Bu bölümde salınım hareketlerini (oscillation) öğreneceksiniz. Trigonometri kullanarak sarkaçlar, dalgalar ve dönen nesneler oluşturacağız. Doğadaki periyodik hareketleri simüle etmeyi keşfedeceğiz.

📐 Açı ve Radyan Nedir?

Salınıma başlamadan önce açı birimlerini anlayalım:

  • Derece (°): Tam daire = 360°. Günlük hayatta kullanılır.
  • Radyan: Tam daire = 2π ≈ 6.28. Matematik ve programlamada tercih edilir.

p5.js'te açı dönüşümü için:

let derece = 90;
let radyan = radians(derece);  // 90° → π/2 ≈ 1.57

// Veya tersi:
let aci = degrees(radyan);     // π/2 → 90°
